# Схема результатов

CSV записаны в UTF-8 без BOM, разделитель — запятая, перенос строки — LF. Поля с запятыми экранированы по стандарту CSV. Идентификаторы arXiv и DOI следует импортировать в электронную таблицу как текст. `NA` — явное неприменимое/неизвестное значение; пустых ячеек нет.

Первые 11 полей `preprints.csv` соответствуют 11 русским колонкам `preprints_ru.csv` в том же порядке.

| Поле | Значение |
|---|---|
| `preprint_title` | Название **первой версии**, пробелы нормализованы |
| `arxiv_id` | ID без номера версии |
| `first_version_date` | UTC-дата подачи v1, YYYY-MM-DD |
| `published` | `да` — подтверждена журнальная версия к срезу; `нет` — такая версия не установлена по принятому определению |
| `venue` | Название журнала из метаданных публикации; NA при ненайденной журнальной версии |
| `publication_doi` | Нормализованный DOI журнальной версии, не DOI препринта или исправления |
| `sjr_quartile` | Q1–Q4, лучший квартиль SJR 2025; NA — журнал не сопоставлен/нет в рейтинге или публикация не установлена |
| `publication_date` | YYYY-MM-DD, YYYY-MM или YYYY с исходной точностью; NA, если версия не найдена |
| `delay_days` | Целое число календарных дней для точной прямой хронологии; NA при неполной дате, выпуске до v1 или ненайденной версии |
| `title_changed` | `да`/`нет` при найденной статье, сравнение компактных нормализованных названий; NA, если сравнивать не с чем |
| `match_confidence` | `высокая`/`средняя`/`низкая`, уровень подтверждения идентичности, не калиброванная вероятность |
| `publication_title` | Название опубликованной версии, HTML/MathML-разметка удалена |
| `date_precision` | `day`/`month`/`year`/NA |
| `date_source` | Явное поле источника выбранной даты |
| `delay_lower_days`, `delay_upper_days` | Границы прямого ожидания для неполной даты; при точной прямой дате обе равны `delay_days`; при полностью обратной хронологии NA |
| `match_route` | Идентификаторные/поисковые пути, по которым найден кандидат; отдельная метка миграции DOI |
| `sjr_source_id`, `sjr_title`, `sjr_categories` | Идентификатор, каноническое название и все категории исходной строки SJR |
| `latest_arxiv_title` | Название последней доступной версии для резервного поиска |
| `arxiv_doi_present` | Есть ли DOI в выгрузке arXiv; не вывод о наличии DOI вообще |
| `status_reason` | Найденная журнальная версия, обратная хронология или отсутствие принятого совпадения |
| `inspire_refereed` | `да`/`нет`/NA: явный флаг INSPIRE; отсутствие флага не приравнивается к отрицанию рецензирования |
| `excluded_proceedings_doi`, `excluded_proceedings_venue` | Подтвержденная публикация в сборнике, исключенная из основной журнальной метрики; ее существование не теряется при статусе `нет` |

Для 19 строк со статусом `нет` наличие публикации **в сборнике** возможно: такие случаи исключены из основной журнальной метрики. Это объясняется в отчете и диагностике, а не скрывается за словом «неопубликовано».

## Статистика

- `published_fraction`: 181/200.
- `q1_fraction_published`: 69/181; неизвестный квартиль остается в знаменателе.
- `q1_fraction_sample`: 69/200.
- `mean_delay_days`, `median_delay_days`: только 176 точных неотрицательных прямых задержек.
- `mean_delay_lower_bound`, `mean_delay_upper_bound`: средние границы по 180 прямым наблюдениям, включая четыре месячные даты; публикация до v1 исключена из обоих знаменателей.
- `wilson95`: интервал Уилсона для доли 181/200, без оценки ошибок обнаружения и без поправки на конечную совокупность.
- `renamed_n`: различие нормализованных текстовых названий, а не обязательно радикальное семантическое изменение.

Строки `funnel.csv` — именованные этапы с явным числом, не все являются последовательными вложенными подмножествами: Q1 и точная задержка — разные конечные характеристики опубликованных работ. `discovery_branches.csv` отдельно показывает ветвление по наличию DOI arXiv.

`chronology.csv` хранит **подписанную** разность дат. Значение −36 для 2109.03271 — подтвержденная последовательность событий, не ошибка округления даты. Этот столбец не является столбцом прямого ожидания из таблицы сдачи.

## Проверочный эталон

`gold.json` — статические заключения с источниками. `baseline_published` — исходное предсказание до исправления нормализации фамилии. `expected_published`, `accepted_dois`, `expected_publication_date`, `expected_delay_days` — фактические ожидания для повторной проверки. Поля gold читаются **после** получения 200 предсказаний.

`validation.json` считает отдельно ошибки статуса, DOI, даты и задержки и число случаев с хотя бы одной ошибкой. Один случай с несколькими ошибками не увеличивает общее число ошибок в случаях дважды. Группы перекрываются; их размеры нельзя складывать как независимые наборы. Всего 29 уникальных препринтов: аудит 20, контрольные 5, спорные 5, причем 2111.07453 уже входит в аудит.
