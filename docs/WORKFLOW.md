# Сбор и проверка данных

`make verify` проверяет контрольные хеши замороженных итоговых файлов. `make refresh` получает API-ответы и сохраняет новый снимок в `data/live/<UTC timestamp>/`, не перезаписывая сдачу.

Метаданные собираются из API arXiv, INSPIRE-HEP, Crossref и OpenAlex, а данные SJR 2025 загружаются из опубликованных копий. Для статьи Acta Physica Polonica B с DOI `10.5506/aphyspolb.54.6-a2` Crossref и INSPIRE указывают только год. Сборщик получает URL первичного источника из записи Crossref, напрямую запрашивает HTML издателя и принимает точный день только если ответ подтверждает DOI, номер статьи и явную строку `published online YYYY-MM-DD`.

При новых результатах сравните таблицы, даты, метрики, отчёт и презентацию с материалами сдачи. Сначала сохраняйте пересчёты в отдельном временном каталоге. Обновляйте замороженные результаты только вместе с описанием каждого различия и его причины.

Сырые ответы, снимки страниц и sidecar-метаданные с URL, датой получения и SHA-256 сохраняются как источники и история происхождения данных. Не подменяйте неполный год или месяц точным днём. Если первичный источник недоступен или не подтверждает день, сохраняйте доступную точность, оставляйте `delay_days` пустым и пересчитывайте среднее только по точным задержкам.
