# Источники, снимок и происхождение данных

Срез исследования — **2026-11-05**, календарные даты arXiv трактуются в UTC. Сырые ответы сохранены побайтно. Соседние `.meta.json` содержат URL запроса, HTTP-статус, время получения, SHA-256 и доступные заголовки ответа. Ответы crawl4ai хранят URL и Markdown; для двух первоначальных страниц сохранена исходная оболочка ответа инструмента. Общий манифест `INPUTS.sha256` покрывает и эти файлы.

| Папка | Источник и назначение |
|---|---|
| `data/raw/arxiv/` | Atom API: полный категорийный запрос за 2021 год, все страницы и 200 первых версий |
| `data/raw/inspire/` | INSPIRE literature API, точный поиск каждого из 200 ID; запрошенные поля ограничены метаданными, без огромных списков ссылок |
| `data/raw/refereed/` | INSPIRE, отдельные пакетные запросы флага рецензирования и типов документов для всех 200 ID |
| `data/raw/crossref/` | Полные записи DOI, поисковые ответы по названиям; ответы 404 сохранены как получены, поэтому файл с расширением `.json` для такого ответа может содержать простой текст ошибки |
| `data/raw/openalex/` | Первые пять результатов поиска по последнему/первому названию для ненайденных журнальных версий; тип preprint не приравнивается к журнальной статье |
| `data/raw/journals/` | INSPIRE journals: название, ISSN и идентичность журналов, когда регистрационных данных DOI недостаточно |
| `data/raw/review/` | Дополнительные точные запросы для разбора близких, но чужих статей |
| `data/raw/pages/` | Страницы arXiv, издателей, автора и документации через crawl4ai `md`, фильтр raw. Недоступная страница или CAPTCHA не используется как подтверждение статьи |
| `data/raw/texts/` | Открытый опубликованный текст Acta Physica Polonica B, 54, 6-A2 (2023); на первой странице явно указано 11.07.2023 |
| `data/raw/sjr/` | Два полных одинаковых CSV SJR 2025, ответы GitHub API с коммитами, метаданные загрузок |

Базовые адреса: [arXiv API](https://info.arxiv.org/help/api/user-manual.html), [INSPIRE REST API](https://github.com/inspirehep/rest-api-doc), [Crossref API](https://api.crossref.org), [OpenAlex API](https://api.openalex.org).

Проверено 29 уникальных препринтов. Для положительных вердиктов сопоставлены авторы, название/его история, DOI и издательская запись; доступны также страницы издателей. Для отрицательных сопоставлены arXiv и INSPIRE и просмотрены поисковые кандидаты; это ограниченный источниками вердикт. Для 2110.14616 дополнительно сохранена [страница исследования Brian Williams](https://sites.google.com/view/brianrwilliams/research). Для 2112.15592 прочитан опубликованный полный текст и сверена дата на первой странице. Издательская страница и PDF различают Regular Series и Proceedings Supplement. Поиск по названию ограничен пятью результатами на запрос; возможны пропуски вне этой выдачи.

Флаг INSPIRE `refereed=true` есть у 180 принятых публикаций; у **2112.00763**, Communications Physics, он не заполнен. Сохранены страницы журнала Nature Portfolio и его редакционной политики. Единственное явное `refereed=false` в выборке относится к исключенному материалу, а не к принятой журнальной статье. Для отсутствующего в SJR Journal of Mathematics Research отдельно сохранена страница журнала с описанием внешнего рецензирования; отсутствие рейтинга не использовалось как запрет считать публикацию.

## SCImago SJR 2025

Оригинальный источник справочника — [SCImago Journal & Country Rank](https://www.scimagojr.com/journalrank.php?year=2025). Прямые запросы страницы и выгрузки были недоступны (403/ошибка сервиса), поэтому использованы две архивные копии **полного**, а не отфильтрованного справочника:

1. [P-M-Ferreira/ranking, коммит 189c0e9887085ada9a2af20b725b64617448830a](https://raw.githubusercontent.com/P-M-Ferreira/ranking/189c0e9887085ada9a2af20b725b64617448830a/scimagojr%202025.csv).
2. [bastianaravenaulagos/DATOS_SCIMAGO_REVISTAS, коммит 4984bb4fb542904ac5ff9cb446e442ff94fd9409](https://raw.githubusercontent.com/bastianaravenaulagos/DATOS_SCIMAGO_REVISTAS/4984bb4fb542904ac5ff9cb446e442ff94fd9409/scimagojr%202025.csv).

Обе копии имеют **11 248 204 байта** и SHA-256:

```text
ead12360e11e9ebc2f4eb7280315540d0bfac69897f9f3b722ebe5039c43d523
```

Заголовок включает `Total Docs. (2025)`. Использованы поля `Issn`, `Title`, `SJR Best Quartile`, `Sourceid` и `Categories`. Совпадение двух зеркал удостоверяет равенство копий, но не является независимым подтверждением первичной выгрузки SCImago. Этот предел происхождения раскрыт, год не подменялся 2024-м. Использование лучшего квартиля и ретроспективного года 2025 объяснено в отчете и шпаргалке.

## Два вида справочников и эталон

- `data/reference/doi_aliases.json` — фактологическая связь старого и нового DOI TÜBİTAK и документированное решение о конфликте дат. Эти сведения используются в конвейере и ссылаются на сохраненные первичные источники.
- `data/review/gold.json` — ожидаемые исходы для проверки уже полученных предсказаний. Он не подставляет публикационные статусы в алгоритм. Поскольку проверочный набор помог исправить нормализацию, он не является независимым тестом.

## Версии программных компонентов

- CPython 3.12, эталонная версия 3.12.3.
- ReportLab 4.4.4: компиляция PDF и векторных графиков, режим `invariant=1`.
- Pillow 12.0.0 и charset-normalizer 3.4.4: закрепленные зависимости ReportLab, локальные колеса Linux x86_64 / CPython 3.12.
- DejaVu Sans / DejaVu Sans Bold: включены TTF-файлы и их исходная лицензия. Системный набор шрифтов не влияет на PDF.
- SVG, CSV, JSON и все численные расчеты: стандартная библиотека Python.

Фиксированные дата среза, seed, сортировки, шрифты, версии и режим PDF исключают часы системы, случайный порядок словарей и сетевые ответы из обычной пересборки. Внутренняя техническая дата PDF при инвариантной сборке — 01.01.2000; дата исследования явно напечатана в документе и не берется из этого поля.

Кодовая лицензия не распространяется автоматически на сырые данные, чужие страницы и пакеты. В исходных файлах сохранены сведения правообладателей; опубликованный текст Acta Physica Polonica B содержит указание CC BY 4.0, лицензия шрифтов лежит рядом с ними, лицензии пакетов входят в wheel-архивы.
